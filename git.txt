### task: copy from remote git to local directory:
// note: dir with project will be auto created
// do not create dublicate...
git clone https://github.com/mbox54/blocknote.git
************************************************************

### task: copy dir source to new remote network git:
1) create network new rep
// note: it creates net address with it

2) create local git with:
git init

// (git add README.md)
git commit -m "first commit"
// branch may be renamed from master to main...
git branch -M main

// bind remote link address
git remote add origin https://github.com/mbox54/blocknote.git

3) add local dir files
git add .

4) send to remote git
git push -u origin main
************************************************************

### task: update git data
1) show updates
git status

2) append new files (if exist)
git add .

3) commit
git commit -m "add files"

4) send
git push
